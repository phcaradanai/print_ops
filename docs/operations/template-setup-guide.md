# Template Setup Guide

คู่มือนี้สำหรับ Admin ขึ้นไป

## สร้าง Paper Profile

1. เข้าเมนู `Paper Profiles`
2. กำหนด `code`, ชื่อ, width/height mm, margins และ dpi
3. ใช้ preset เช่น 100x50 mm หรือ 80x50 mm เป็น baseline ได้
4. บันทึกแล้วนำไปใช้กับ template หรือ binding

## สร้าง Template

1. เข้าเมนู `Templates`
2. เลือก engine เช่น `RAW_TEXT`, `ZPL`, `TSPL`
3. ใส่ content โดยใช้ placeholder แบบ `{{field}}`
4. เลือก paper profile
5. กด preview เพื่อตรวจ missing field
6. Publish เมื่อพร้อมใช้งาน

## ผูก Printer กับ Template

1. เข้าเมนู `Bindings`
2. เลือก `printer_code`
3. เลือก `template_code`
4. เลือก paper profile
5. ตั้ง `is_default` ถ้าเป็น template หลักของ printer นั้น

## ข้อจำกัดของแต่ละฟิลด์

ทุกฟิลด์ต้องมีจุดอ้างอิง (X, Y) อยู่บนกระดาษเสมอ ถ้าจุดอยู่นอกกระดาษ ระบบจะไม่ให้บันทึก เพราะไม่มีอะไรถูกพิมพ์ออกมา

| ชนิดฟิลด์ | ต้องพอดีกับขอบเขตกระดาษหลังการหมุน |
| --- | --- |
| `text`, `date`, `number` | พิมพ์บรรทัดเดียวไม่ตัดขึ้นบรรทัดใหม่ จำนวนตัวอักษรต่อบรรทัด = พื้น(ความกว้างที่เหลือ ÷ ความกว้างตัวอักษร) โดยตัวอักษรกินที่ประมาณ 0.6 เท่าของขนาดฟอนต์ เช่น 12 pt ≈ 2.54 มม./ตัวอักษร |
| `barcode` | `barcodeWidthMm` × `barcodeHeightMm` ต้องอยู่ในกระดาษ (ถ้าถูกตัดจะสแกนไม่ติด) |
| `qrcode` | `qrSizeMm` บวก quiet zone รอบละไม่เกิน 4/21 ของขนาดสัญลักษณ์ ต้องอยู่ในกระดาษ |

ตัวอย่าง: label กว้าง 100 มม. ขอบ 2 มม. วางฟิลด์ที่ X = 3 มม. และขนาดฟอนต์ 12 pt จะพิมพ์ได้ 37 ตัวอักษรต่อบรรทัด (ลดขนาดฟอนต์เหลือ 9 pt ได้ประมาณ 49 ตัวอักษร)

ข้อความที่ยาวเกินจะ **ไม่บล็อกการบันทึก** แต่จะขึ้นคำเตือนที่การ์ดของฟิลด์นั้น เนื่องจากตัวเลขที่พิมพ์จริงคือค่าของฟิลด์ (value) ไม่ใช่ label ในเครื่องมือแก้ไข ส่วน barcode/QR ที่ล้นขอบเป็นข้อผิดพลาดที่บันทึกไม่ได้ เพราะภาพที่ถูกตัดจะอ่านค่าไม่ได้

แผงแก้ไขจะแสดงงบประมาณของแต่ละฟิลด์ไว้ใต้ช่องของฟิลด์นั้น (จำนวนตัวอักษร หรือขนาดโค้ดที่วางได้) โดยปัดเป็นทศนิยม 1 ตำแหน่งแบบไม่ให้เกินค่าที่พิมพ์ได้จริง

## สิ่งที่ต้องยืนยัน

- ขนาด label จริงตรงกับ paper profile
- template code อยู่ใน printer allowlist
- printer code เป็น printer ที่ runner/register แล้ว
