Use case: ui-mockup
Asset type: High fidelity multi-screen UX/UI design proposal board for the existing PrintOps hospital print orchestration web app.
Primary request: Redesign the web UX to be easier to use and give ALL pages a coherent shared design system. Create an exceptionally crisp, professional, realistic UI design board, landscape 3:2, high resolution. Four large readable desktop screens arranged in an exact 2 by 2 grid, each screen showing an entire application viewport with its own identical narrow sidebar and header. Above the grid a very modest heading "PrintOps / Unified operations" and subtitle "UX/UI concept · Sample data". Label screen captions 01 Overview, 02 Job queue, 03 Printers, 04 Settings. Use screen space efficiently with generous internal padding and legible content, avoid tiny illegible decorative paragraphs.
Product reality: on-premise hospital printer gateway, existing capabilities include overview, jobs, printers, runners, templates, paper profiles, webhook endpoints, bindings, audit, users and settings. Outcome UNVERIFIED means sent but physical printing not confirmed; it must stay amber and separate from SUCCESS, never automatic reprint. No actual patient names, personal information or invented performance claims.
Art direction: calm clinical precision, understated elegant operations software, warm off-white overall board, white application canvases, slate text, thin cool-gray separators, blue #1e66f5 primary actions. Sidebar deep ink #1e1e2e, soft blue active row, crisp white PrintOps wordmark with a small simple printer outline mark. Flat surfaces, 6-8px corner radii, restrained shadows only on a detail drawer. No gradients, glass, 3D, stock photographs, neon, giant number cards, ornamental charts or marketing hero. Consistent practical typography inspired by IBM Plex Sans Thai / Inter, 24px screen titles, 14px body, 44px controls, 8px spacing rhythm. Status chips have icon AND text, readable contrast.
Shared sidebar in every screen, same order: Overview; OPERATIONS group Job queue, Printers, Runners; CONFIGURATION group Templates, Paper profiles, Connections; ADMINISTRATION group Audit log, Settings. Compact user/avatar at bottom. Same slim top bar with breadcrumb left, "Local gateway" connection state, TH / EN selector and user right. Use English for dense navigation and table labels, with clear Thai main page titles exactly "ภาพรวม", "คิวงานพิมพ์", "เครื่องพิมพ์", "ตั้งค่า" if possible. No uppercase letterspacing on Thai.

Prominent compact amber action strip "3 jobs need confirmation" and link "Review jobs". Below a single low-height horizontal summary strip with Queued 12, Printing 4, Unverified 3, Failed 1, clearly segmented; do NOT make four large cards. Main two-column region: wide Recent jobs simple tidy table with Job, Printer, Status, Time; narrower Printer health list with Ward A Ready, Laboratory Paper low, Pharmacy Offline. At bottom small latest activity list. Meaningful examples JOB-1048, LABEL-WARD-A.
